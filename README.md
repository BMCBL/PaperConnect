# PaperConnect

PaperConnect 帮你在 BMCBL 里创建和分享《Minecraft》基岩版联机房间。房主打开自己的世界，好友用联机码加入。

## 首次安装

1. 在 BMCBL 打开「下载 → 插件」，找到 PaperConnect 并点击安装。
2. 打开「工具 → 联机大厅」，按页面提示下载并安装原生组件。
3. 下载完成后，在 BMCBL 的授权提示中确认。返回联机大厅，就能创建或加入房间。

房主和好友都需要安装 PaperConnect。建议大家使用相同版本的《Minecraft》基岩版。

## 房主创建房间

1. 先进入要分享的世界，在世界设置中开启多人游戏和局域网可见。
2. 保持世界开启，回到 BMCBL 的「工具 → 联机大厅」，点击「创建房间」。
3. 把生成的联机码发给好友。创建后联机码会自动复制，也可以点击「复制联机码」。

## 好友加入房间

1. 在联机大厅输入或粘贴房主发来的完整联机码，然后点击「加入」。
2. 等页面显示已连接，再打开《Minecraft》基岩版。
3. 在游戏的「好友」页面找到房主的局域网世界并加入。结束后回到联机大厅断开连接。

## 遇到问题

- **创建时找不到世界**：确认房主已进入世界，并在游戏里开启多人游戏和局域网可见，然后重试创建。
- **已连接，但游戏里找不到世界**：先确认房主还留在同一个世界。若联机大厅提示本机发现端口被占用，请先关闭占用端口的程序，再点击「重试发现」。
- **联机码无效**：重新复制房主发来的联机码，保留开头的 `P/` 和中间的连字符。
- **组件安装失败**：确认网络可用，并查看 BMCBL 的下载或授权提示，再回到联机大厅重试。

插件更新在「下载 → 插件」中完成。原生组件可在联机大厅检查更新。
